# Reto Hospital San Gabriel — De registros a datos

**Informática Médica · Semana 12 · Actividad individual.**

> **Datos 100 % ficticios.** No subas datos de pacientes reales a GitHub.

## Tu misión

El hospital recibió 20 anotaciones clínicas en distintos formatos. Tu trabajo consiste en convertirlas en una base de datos bien estructurada, analizarla y publicar tu solución en tu propio repositorio de GitHub.

## Descarga del material

1. En este repositorio del docente, selecciona **Code → Download ZIP**.
2. Extrae el ZIP y lee `CASO_CLINICO.md` y `INSTRUCCIONES.md`.
3. No modifiques el repositorio del docente; trabaja en tu computador.

## Entrega

Crea un repositorio público en tu propia cuenta llamado `hospital-san-gabriel-solucion` y sube:

```text
hospital-san-gabriel-solucion/
├── Base_Datos_Hospital.xlsx
├── pacientes.csv
├── README.md
└── analisis.md
```

En la plataforma institucional entrega la URL de tu repositorio personal.

## Criterios de evaluación

| Criterio | Puntos |
|---|---:|
| Diseño de campos y estructura | 15 |
| Limpieza y estandarización de 20 registros | 30 |
| Fórmulas, estadísticas y dos gráficos en Excel | 25 |
| Documentación y análisis | 15 |
| Publicación correcta en GitHub | 15 |
| **Total** | **100** |

**Nota:** Este repositorio contiene únicamente el material inicial. No incluye una base de datos resuelta.
